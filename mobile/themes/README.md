# Темы

Здесь лежат встроенные темы, выгруженные в JSON — как образцы для собственных.
Приложение читает их из кода (`src/ui/theme/themes/`), эти файлы нужны только
чтобы было с чего начать.

Пересобрать после правки встроенных тем: `npm run themes:export`.

## Из чего состоит тема

**Два слоя цвета.** `palette` — сырые цвета с любыми именами, какие удобны
автору схемы. `colors` — роли в интерфейсе, которые на них ссылаются через
`$имя`. Разделение нужно, чтобы варианты одной схемы (Latte / Mocha)
отличались только палитрой, а назначения не переписывались заново.

```json
"palette": { "base": "#1e1e2e", "mauve": "#cba6f7" },
"colors":  { "bg": "$base", "accent": "$mauve", "scrim": "$base@70" }
```

`$имя@70` — тот же цвет с прозрачностью 70%.

**`onAccent` выводится сам.** Если тема задаёт `accent`, но не задаёт подпись
на нём, она подбирается автоматически — чёрная или белая, по контрасту. Иначе
унаследованное значение почти наверняка не подошло бы к новому акценту, и
тема из четырёх строк сразу упиралась бы в проверку читаемости. Явно
указанный `onAccent` не трогается.

**Наследование.** `extends` указывает на `base-dark` или `base-light`; всё
неуказанное доезжает оттуда. Минимальная рабочая тема:

```json
{
  "schema": "ytmusic-theme/1",
  "id": "my-rice",
  "extends": "base-dark",
  "colors": { "accent": "#89b4fa", "onAccent": "#11111b" }
}
```

## Что меняется кроме цвета

| Ключ | Что делает |
|---|---|
| `radius` | Скругления обложек, карточек, шторок, чипов. Нули — пиксельный вид |
| `typography.family` | Гарнитура из встроенного набора: `system`, `IBM Plex Sans`, `Handjet`, `Pixelify Sans` |
| `typography.scale` | Множитель кегля, 0.5–2 |
| `typography.letterSpacing` | Разрядка в долях кегля. Точечным шрифтам нужна положительная |
| `layout.density` | `compact` или `comfortable` — высота строк списка |
| `motion.scale` | Множитель длительности анимаций. `0` — мгновенно, без сглаживания |
| `components.playButton` | `circle`, `square`, `pill` |
| `components.progress` | `line` или `stepped` (сегментами) |
| `components.thumb` | `rounded`, `square`, `circle` |
| `components.tabBarLabels` | Показывать подписи под иконками вкладок |
| `decor.overlay` | `none` или `scanlines` |

## Что проверяется при применении

Тип каждого знакомого ключа — с понятным сообщением («`radius.card`: ожидается
число, получено «8px»»). Незнакомые ключи игнорируются, чтобы тема из будущей
версии всё-таки открылась.

Отдельно считается контраст. Если текст на фоне читается хуже 4.5:1, тема
**не применяется**: иначе можно собрать оформление, в котором не найти
настройки, чтобы его сменить. Пороги видны на экране «Оформление», а в
редакторе рядом с ошибкой есть кнопка «Подобрать читаемые» — она чинит только
цвета переднего плана (на чёрный или белый), фон и акцент оставляет как есть.

Чего проверка **не** ловит: фон экрана «Сейчас играет» выводится из обложки,
а не из палитры темы. Он согласуется с темой по светлоте отдельно
(`src/ui/artworkColor.ts`) — если добавляете туда цвета, помните, что
контрастный порог их не прикроет.

## Шрифты

Тема называет гарнитуру по имени — файла шрифта в JSON нет и быть не может.
Набор встроен в приложение, неизвестное имя молча даёт системную гарнитуру.

Добавляя гарнитуру, проверяйте наличие кириллицы. У `Silkscreen` и
`Press Start 2P`, которые первыми просятся для пиксельной темы, её нет:
латиница отрисовывалась бы растровым шрифтом, а русский текст — системным.
Поэтому взят `Handjet` — точечный и с кириллицей.

## Как темы попадают в приложение

На экране «Оформление» → «Своя тема»:

- **Открыть редактор** — правка ползунками, изменения видны сразу на всех
  экранах; предпросмотра нет намеренно, предпросмотром служит само приложение.
- **Импорт из файла** — выбрать `.json` на устройстве.
- **Вставить из буфера** — самый быстрый способ принять тему из чата.
- **Загрузить по ссылке** — прямая ссылка на `.json`, например «raw» с гиста.
- **Скопировать / Поделиться** — отдать текущую тему в буфер или файлом.

Импортированные темы попадают в раздел «Мои темы» и хранятся целиком: исходный
файл мог быть удалён сразу после импорта. Встроенные хранятся только по
идентификатору — тогда их правки доезжают с обновлением приложения, а не
застревают в снимке, сделанном при выборе. Долгое нажатие на карточку своей
темы удаляет её.

Сохраняются только темы, прошедшие проверки: иначе в списке копились бы
заведомо нерабочие.
